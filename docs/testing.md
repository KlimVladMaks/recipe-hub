# Тестирование

В проекте два независимых набора проверок: E2E-тесты на `node:test` и
Postman-коллекция, которая запускается через Newman. Оба работают «чёрным
ящиком» — только через API-шлюз по HTTP, без доступа к коду и базе.

## E2E-тесты

```bash
cd tests
npm install
npm test              # стек уже поднят
npm run test:stack    # поднять стек и сразу прогнать тесты
```

Стек: встроенный `node:test` + `assert`, запуск через `tsx`. Тесты лежат в
`tests/e2e/` и сгруппированы по темам:

| Файл | Что проверяет |
|---|---|
| `health.test.ts` | доступность шлюза и сервисов |
| `auth.test.ts` | регистрация, вход, смена пароля, профиль |
| `users.test.ts` | список пользователей, роли, подписки, лента |
| `recipes.test.ts` | CRUD рецептов, фильтры, черновики, медиа |
| `steps-comments.test.ts` | шаги, комментарии и лайки |
| `social.test.ts` | рейтинги, сохранения, подписки |
| `admin.test.ts` | справочники и админские операции |
| `main-flow.test.ts` | сквозной пользовательский сценарий |
| `validation.test.ts` | негативные проверки и коды ошибок |

Правила, которые держат прогон чистым: каждый тест создаёт свой контекст,
регистрирует созданные сущности и удаляет их в `after()`. Bootstrap-админ — это
служебная seed-запись, она не удаляется. Подробности — в
[tests/README.md](https://github.com/KlimVladMaks/recipe-hub/blob/main/tests/README.md).

## Postman / Newman

```bash
cd tests
npm run test:postman
```

Коллекция содержит 52 запроса: health, работа админа со справочниками, сквозной
пользовательский сценарий и полная очистка с проверкой удаления. Запуск против
облака — с окружением `cloud` или `--env-var baseUrl=...`. Описание —
в разделе [Postman](postman.md).

## Что проверяется в CI

Workflow `.github/workflows/ci.yml` запускается на каждый push и pull request:

| Джоба | Содержание |
|---|---|
| `Typecheck` | `tsc --noEmit` для `api-gateway`, `user`, `recipe` и `tests` |
| `OpenAPI lint` | `redocly lint docs/openapi.yaml` — синтаксис и ссылки спецификации |
| `E2E` | `docker compose` со случайным `JWT_SECRET`, 52 E2E-теста, Newman, логи артефактом |

Облако в CI не используется, поэтому прогон ничего не стоит. Доставка в облако
вынесена в отдельные ручные workflow — см. раздел [Развёртывание](deployment.md).
